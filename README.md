# NexusBadgeChecker

**NexusBadgeChecker** is a fast, browser-based NFT tracker built for the **Nexus Labs** ecosystem.  
It allows users to view all owned and missing badge NFTs across Base and Ethereum networks.

## 🧩 Features
- Real-time wallet scan for Nexus badge collections  
- Detects owned vs missing NFTs  
- Displays mint count per contract  
- Clean, pastel UI optimized for performance  
- Hosted on [Caffeine.xyz](https://nexusbadgechecker-0hw.caffeine.xyz/)

## ⚙️ Stack
- React + Tailwind CSS  
- Ethers.js  
- BaseScan / EtherScan APIs  
- JSON-based contract index  

## 🚀 Usage
1. Visit [nexusbadgechecker-0hw.caffeine.xyz](https://nexusbadgechecker-0hw.caffeine.xyz/)  
2. Connect your wallet  
3. Instantly see all Nexus badge data — owned, missing, and mint counts.
